# university-json-analyzer

Парсинг большого JSON (более 10 тысяч строк) и расчёт среднего балла студентов.

## Что делает программа

- Читает JSON-файл с данными об университетах, факультетах, курсах и студентах.
- Находит всех студентов и их оценки.
- Вычисляет средний балл (сумма оценок / количество).
- Выводит результат в консоль.

## Как запустить

1. Убедись, что установлен Python 3.8+.
2. Скачай репозиторий или скопируй файлы `main.py` и `universities_big.json` в одну папку.
3. Открой терминал в этой папке и выполни:
python main.py
